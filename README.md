# 현장컷 홍보메이커

> 현장 사진과 제품만 고르면, 티링크 공식 자료에 근거한 블로그 원고·카드뉴스 4컷·문자 문구를 만들고, 월간 홍보 가이드라인 준수 여부와 근거 없는 주장을 **코드로 검사**하는 마케팅 도구

- 대상: 녹취·CRM·인터넷전화 솔루션 기업 티링크의 마케팅 담당자 (월간 가이드라인으로 블로그 리뷰·SNS·문자를 만들고 체험단 원고를 검수)
- 핵심 아이디어: **생성은 AI가, 검사는 코드가.** AI가 쓴 모든 제품 주장 문장에 공식 자료 근거 번호를 달게 하고, 코드가 그 근거와 숫자를 대조한다.

## 동작 흐름

```
현장 사진 + 제품 + 업종
   │
   ▼
① AI 사진 분석 (Gemini)
   - 장면 태그 분류, 확신 낮으면 「확인 필요」
   - 사진 속 글자 읽기 → 코드가 전화번호 패턴으로 한 번 더 검사 (개인정보 이중 검사)
   - 공식 팩트시트 33문장 중 맞는 기술 차별점 3개 + 출처 파일·페이지
   │   (사진 속 글자는 다음 단계로 넘기지 않음)
   ▼
② AI 콘텐츠 생성 (Gemini)
   - 블로그 원고(가이드라인 5단 구성), 카드뉴스 4컷, SMS 90byte 문자
   - 제품 주장 문장마다 〔F05〕 같은 근거 번호, 가이드라인 요구 문장은 〔G〕
   ▼
③ 코드 검수 (checker.py, AI 아님)
   - 가이드라인 17개 항목: 필수 키워드 3개(제목·본문), 첫 문단 키워드 4개, 리뷰 미션 11개,
     이미지 5종 순서, 하단 연락처, 문자 길이, 카드 4컷
   - 의미 판단이 필요한 미션(후기 형식, 결론)은 「사람 확인」으로 분리
   - 팩트락: 근거 번호 없는 제품 주장 / 없는 근거 번호 / 근거와 다른 숫자 / 팩트시트에 없는 숫자 → 「확인 필요」
   - 「확인 필요」를 모두 확인 완료해야 내려받기 활성화 (근거 번호는 자동 삭제)
   ▼
④ (선택) 비교 실험: 같은 사진을 일반 프롬프트로 생성해 같은 검수기로 채점
```

## 시험 결과

### 검수기 정확도 (`python tests/run_eval.py`)
정상 원고 1건 + 문제를 심은 원고 17건(누락 7, 왜곡 10)

- 문제 원고 17건 중 **16건 탐지 (94%)**, 정상 원고 **오탐지 0건**
- 탐지 예: 99%→95% 수치 변조, 근거 없는 「상담 시간 30% 절감」, 요금 3만원→2만원, 학교 납품 근거에 붙인 「한국전력 3,000석」, 존재하지 않는 근거 번호, 본문·사진 속 개인 전화번호, 필수 키워드 누락, 이미지 순서 오류, 문자 90byte 초과
- 놓친 1건: 숫자·기능 단어가 없는 새 기능 주장(「카카오톡 상담 저장」) → 다음 단계 보완 대상
- 상세 표: [tests/eval_result.md](tests/eval_result.md)

### 실제 생성 시험 (배포 앱, Gemini 3.8 Flash)
- 병원 현장 사진 1장: 가이드라인 17개 항목 모두 충족, 근거 번호 없이 쓴 문자 문구 1건을 「확인 필요」로 탐지
- 차별점 매칭: 병원 업종에 「성형외과·피부과 100여 곳 운영」(회사소개서 p.4) 등 3개를 출처와 함께 제시
- 소요 시간: 사진 분석 81초, 콘텐츠 생성 178초 (1단계 목표 30초·1분 미달)

## 파일 구조
| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 화면 |
| `ai.py` | Gemini 호출 (사진 분석, 콘텐츠 생성, 비교용 일반 생성). 모델을 쓸 수 없으면 다음 모델로 자동 재시도 |
| `checker.py` | 가이드라인 검수, 문장 단위 팩트락, 개인정보 검사 |
| `data/factsheet.json` (또는 루트) | 제안서·매뉴얼 3종·회사소개서에서 뽑은 공식 문장 33개와 출처 페이지 |
| `data/guideline_2026_11.json` (또는 루트) | 11월 가이드라인 규칙. **달마다 이 파일만 교체** |
| `data/demo_result.json` (또는 루트) | API 키 없이 볼 수 있는 데모 결과 |
| `tests/run_eval.py` | 검수기 정확도 시험 18건 |

## 실행
```
pip install -r requirements.txt
streamlit run app.py
```
Streamlit Secrets(또는 환경 변수)에 `GEMINI_API_KEY`를 넣는다. 모델은 `GEMINI_MODEL`로 바꿀 수 있다. 키가 없으면 데모 모드로 동작한다.

## 확장성
가이드라인 JSON과 팩트시트만 바꾸면 체험단·블로그 원고를 관리하는 다른 B2B 솔루션·시공 기업에도 그대로 적용할 수 있다.
